## 📌 About

A collection of **Data Structures and Algorithms (DSA)** programs implemented in **C**.

This repository documents my journey of learning DSA, improving problem-solving skills, and implementing fundamental algorithms.

## 📚 Topics Covered

- **Arrays:** 1D, 2D, Dynamic Arrays
- **Matrices:** Sparse Matrix Operations
- **Linked Lists:** Singly, Doubly, Circular
- **Stacks & Queues:** Implementation and Operations
- **Searching:** Linear, Binary, Interpolation
- **Sorting:** Bubble, Insertion, Selection, Quick, Merge, Heap, Radix
- **Trees:** BST, AVL, Threaded Binary Tree
- **Graphs:** BFS, DFS, Dijkstra's Algorithm
- **Others:** Polynomial Operations, Hashing

*Programs are being added progressively.*

## 🛠️ Tech Stack

- **Language:** C
- **Compiler:** GCC
- **Version Control:** Git & GitHub
